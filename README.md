# Angel One Financial Modelling: Revenue Growth & Cash Flow Analysis

A deep-dive financial modeling project analyzing the revenue streams and cash flow dynamics of Angel One, a leading fintech and stockbroking firm.

## 📊 Project Overview
This project focuses on identifying key performance indicators (KPIs) driving fintech growth, including client acquisition costs, lifetime value, and operational leverage. It transforms raw financial data into a comprehensive modeling framework.

## 🛠️ Technology Stack
- **Excel**: Advanced financial modeling, sensitivity analysis, and cash flow forecasting.
- **SQL**: Data extraction and transformation for structural financial analysis.
- **Tableau**: Visualizing financial trends and growth metrics.

## 📁 Key Components
- \`Angel One.xlsx\`: The core financial model with integrated projections.
- \`Script .sql\`: SQL queries used to aggregate and clean the financial datasets.
- \`Angel_One_Financial_Modeling_Report.pdf\`: A detailed executive summary of the findings.
